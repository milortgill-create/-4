# POLYGON 01 — физический полигон

Офлайн 3D sandbox от первого лица для Android в горизонтальном режиме. Никакого внешнего подключения: предметы, физика, манекены и система выживания работают локально.

Версия 1.3.0. APK подписан тестовым Android debug-ключом и устанавливается напрямую на Samsung Galaxy A53 и другие устройства Android 6.0+. Если Android спросит, разрешите установку приложений для используемого браузера или файлового менеджера. Приложению не требуется доступ к интернету. Если обновление не устанавливается поверх предыдущей Arena-сборки из-за тестовой подписи, удалите старую сборку и установите эту заново.

## Что внутри

- Полноэкранная горизонтальная Android-игра со встроенной Three.js-сценой.
- Минимальный игровой экран: компактная панель здоровья и состояния тела сверху слева, джойстик слева и кнопка «ДЕЙСТВИЕ» справа.
- Свайп по игровой сцене поворачивает камеру. Сильное отклонение джойстика включает бег; игрок быстрее агрессивного манекена и может убежать от него.
- Удерживание кнопки «ДЕЙСТВИЕ» открывает рюкзак. Внутри можно осматривать предметы, доставать их, мягко класть на землю или убирать в сумку.
- Интерактивная схема тела подсвечивает травмы и кровотечения. Здоровье, голод и жажда сохраняются как игровые показатели; тяжёлая травма или потеря здоровья могут привести к смерти.
- D-01 — мирный манекен: после удара падает, поднимается через положение на коленях и уходит в сторону. D-02 — агрессивный: после падения встаёт, преследует игрока и наносит кулачные удары.
- Бетонная камера с 512px текстурами бетона и дерева, рельефными картами, потолочными лампами и мягкими тенями.
- Физические ящики, бочки, бутылки, доски и лопата; рюкзак 8×5 с 3D-моделью персонажа и лимитом веса 30 кг.
- Ограниченные суставы ragdoll, физические границы, пол, стены и потолок.

Физическая модель — лёгкая офлайн-реализация на Cannon-es; ragdoll и суставные лимиты являются игровой аппроксимацией.

## Сборка из исходников

Нужны JDK 17, Android SDK Platform 35 / Build Tools 35.0.0, Gradle 8.9 и Node.js 20.

```bash
cd web
npm ci
npm test
npm run build
cd ..
gradle --no-daemon :app:assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`. GitHub Actions собирает APK для ветки Arena и публикует актуальный файл в стабильном релизе `android-v1`.
