# POLYGON 01 — физический полигон

Офлайн 3D sandbox от первого лица для Android в горизонтальном режиме. Никакого сюжета и внешней сети: только бетонная тестовая камера, предметы и физика.

## Что внутри

- Полноэкранная горизонтальная Android-оболочка с локально встроенной Three.js-сценой.
- Бетонная камера с более детальными 512px текстурами бетона/дерева, рельефными картами, направленными потолочными лампами и мягкими тенями.
- Виртуальный джойстик слева, свайп справа для обзора; на компьютере — WASD, мышь, E.
- Квадратные блочные перчатки с отдельными сегментами пальцев и анимацией сжатия при захвате; предмет остаётся физическим, но не толкает игрока. Отдельные действия: бросить и мягко положить.
- Ящики, бочки, бутылки, доски и лопата с разной массой и размерами ячеек.
- Два составных манекена с ограниченными cone/twist суставами и ragdoll-режимом.
- Шкалы здоровья, голода и жажды; интерактивная схема тела подсвечивает травмы и пульсирующие кровотечения. Тяжёлое ранение шеи или потеря всего здоровья запускают кровавую сцену смерти и отключают управление.
- Рюкзак 8×5: слева вращающаяся 3D-модель оператора, справа сетка предметов. Выбор показывает массу и описание; бутылка занимает 1×1, лопата — 2×3 ячейки. Лимит переносимого веса — 30 кг.
- Границы для игрока и коллайдеры пола/стен/потолка; предмет при удержании сохраняет контакт с геометрией уровня.

Физическая модель — лёгкая офлайн-реализация на Cannon-es; ragdoll и суставные лимиты являются игровой аппроксимацией, а не точной копией GoreBox/Garry's Mod.

## Сборка из исходников

Нужны JDK 17, Android SDK Platform 35 / Build Tools 35.0.0, Gradle 8.9 и Node.js 20.

```bash
cd web
npm ci
npm run build
cd ..
gradle --no-daemon :app:assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`. GitHub Actions собирает его автоматически для ветки Arena и публикует актуальный файл в стабильном релизе `android-v1`.
