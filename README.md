# POLYGON 01 — физический полигон

Офлайн 3D sandbox от первого лица для Android в горизонтальном режиме. Никакого сюжета и внешней сети: только бетонная тестовая камера, предметы и физика.

## Что внутри

- Полноэкранная горизонтальная Android-оболочка с локально встроенной Three.js-сценой.
- Бетонная камера с освещением, разметкой испытательных зон и промышленными деталями.
- Виртуальный джойстик слева, свайп справа для обзора, большая контекстная кнопка действия; на компьютере — WASD, мышь, E.
- Пустые 3D-руки внизу кадра; подбор предмета наводкой, удержание перед камерой и бросок.
- Деревянные ящики, тяжёлые бочки, лёгкие бутылки и доски с разной массой и инерцией.
- Два составных манекена: удар или быстрый физический контакт переводит их из неподвижной позы в ragdoll; суставы используют ограниченные cone/twist диапазоны.
- Камера покачивается при ходьбе и встряхивается при сильном столкновении.
- Статические коллайдеры пола, стен и потолка; физика объектов работает с фиксированным шагом и контактом с полом.

Физическая модель — лёгкая офлайн-реализация на Cannon-es; ragdoll и суставные лимиты являются игровой аппроксимацией, а не точной копией GoreBox/Garry's Mod.

## Сборка из исходников

Нужны JDK 17, Android SDK Platform 35 / Build Tools 35.0.0, Gradle 8.9 и Node.js 20.

```bash
cd web
npm ci
npm run build
cd ..
gradle --no-daemon :app:assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`. GitHub Actions собирает его автоматически для ветки Arena и публикует актуальный файл в стабильном релизе `android-v1`.
