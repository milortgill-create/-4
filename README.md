# POLYGON 01 — v1.6.0 «Снежный двор»

Офлайн 3D sandbox от первого лица для Android в горизонтальном режиме. В этой части добавлены первые механики выживания: снег и лопата, дрова, печь и шкала тепла. Игровой мир, физика, предметы, звуки и эффекты работают локально, без сетевого доступа.

## Снежный двор и выживание

- Игрок появляется с пустым рюкзаком и пустыми руками. FP-руки и модель предмета скрыты, пока предмет или оружие не экипированы/не взяты.
- Вместо бетонного тестового помещения — зимний двор: текстурированный снег на земле, стены сарая из деревянных досок, сугробы, ящики, бочки и старые доски.
- Лопата есть в мире и в тестовом каталоге «ВСЕ ПРЕДМЕТЫ». С лопатой можно черпать снег из сугроба: куча уменьшается, снег появляется на клинке, а переносимый снег замедляет игрока. Действие, направленное на пол, сбрасывает снег и создаёт новый сугроб.
- В углу стоит кирпичная печь; рядом лежат поленья. Возьмите дрова и нажмите действие рядом с печью: она разгорится, появятся огонь и локальный звук потрескивания. Находясь поблизости, игрок постепенно восполняет тепло; вдали от огня шкала медленно убывает.
- Тепло добавлено в компактную панель состояния рядом со здоровьем, голодом и жаждой.

## Игровые системы

- Android HUD: здоровье и показатели выживания сверху слева, кнопки «МЕНЮ» и «ИНВЕНТАРЬ» сверху справа, джойстик слева и действие/оружие справа. Подсказки клавиатуры и мыши не отображаются.
- В каталоге для тестирования — 9 видов оружия и лопата-инструмент. Оружие выбирается вручную; при старте оружие не экипировано. Есть ближний бой, hitscan-стрельба, отдача, вспышка, звуки и перезарядка.
- Манекены получают урон от оружия и переходят в ragdoll. D-01 ведёт себя мирно, D-02 преследует и наносит кулачные удары.
- Здоровье уменьшается только от падений с высоты, ударов NPC или оружия. Обычные предметы и простой контакт с NPC не наносят урон. Голод, жажда и холод отображаются, но сами по себе здоровье не отнимают.
- Рюкзак 8×5 с 3D-моделью персонажа и лимитом веса 30 кг; физические ящики, бочки, бутылки, доски, лопата и поленья можно поднимать, класть, бросать или убирать в рюкзак.
- Все ресурсы и Web Audio генерируются или запускаются локально; сетевые разрешения игре не нужны.

## Сборка из исходников

Нужны JDK 17, Android SDK Platform 35 / Build Tools 35.0.0, Gradle 8.9 и Node.js 20.

```bash
cd web
npm ci
npm test
npm run build
cd ..
gradle --no-daemon :app:assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`. GitHub Actions тестирует Web-логику, собирает APK и публикует актуальный файл в стабильном релизе `android-v1`.
