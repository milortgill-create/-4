## Деревня и жители

- В центре деревни построен прямоугольный сельский супермаркет с большими витринами и красно-зелёной вывеской в духе «Пятёрочки». Это единственное исключение из общего запрета на 3D-вывески.
- Рядом расположен ряд из трёх металлических гаражей с рифлёными воротами.
- На окраине добавлены три руины по фото: длинное кирпичное здание с пустыми оконными и дверными проёмами, обвалившийся кирпичный дом и приподнятая деревянная постройка на стойках. У всех частично разрушенные крыши.
- Остановка, опоры, крыша и скамья имеют физические коллайдеры. Игрок не проходит сквозь их видимые детали.
- В деревне 200 блочных жителей в тёмных и серых куртках; рядом с игроком одновременно отображается не более 15. Они появляются у остановки, магазина, Михтока или у домов и ходят по связанной сети дорог и тротуаров — не по лесу и крышам. Маршруты чередуются между домом, магазином и Михтоком; при беге игрока с оружием жители убегают по пешеходной сети.
- Тётя Зина остаётся неподвижной возле магазина и поворачивает голову к игроку; она не заменяет жителей.
- Сохранены ограждённые участки домов, плавный склон от высокой остановки к центру деревни и старая западная низина с прудом.

## Управление и игровые системы

- Сенсорный HUD: здоровье и показатели состояния, компактные кнопки меню и рюкзака, джойстик, бег, действие и выброс. Подсказки клавиатуры и мыши не отображаются.
- Игрок начинает с пустым рюкзаком и пустыми руками. FP-рук и кулаков нет ни при каких условиях; при экипированном оружии или инструменте видна только его модель.
- Отдельная тестовая песочница содержит лопату, Glock-17 и автомат. В обычном режиме комплект при старте отсутствует.
- В тестовом каталоге доступны 9 видов оружия и лопата. Есть ближний бой, hitscan-стрельба, отдача, вспышки, звуки и перезарядка.
- Предметы можно поднимать, класть, бросать и возвращать в мир; выброшенные предметы получают физический импульс.
- Снег можно черпать лопатой и оставлять на земле; переносимый снег замедляет игрока. Дрова разжигают кирпичную печь, которая даёт локальный свет, звук и тепло.
- Здоровье уменьшается от тяжёлых падений, ударов NPC или оружия. Голод, жажда и тепло отображаются в HUD.
- Сборка содержит локальные модели, текстуры и звуки; сетевые разрешения игре не нужны.

## Сборка из исходников

Нужны JDK 17, Android SDK Platform 35 / Build Tools 35.0.0, Gradle 8.9 и Node.js 20.

```bash
cd web
npm ci
npm test
npm run build
cd ..
gradle --no-daemon :app:assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`. GitHub Actions запускает Web-тесты, собирает APK и обновляет актуальную загрузку в стабильном релизе `android-v1`.
